**Night Gallery — The Starlight Heist** — a top-down stealth game. You are Pip, a moth-thief slipping through a moonlit museum at night. Each of the 3 floors hides starlight shards behind patrolling wardens: gather them all, then reach the green exit unseen. Wardens sweep the halls with ray-clipped vision cones that walls, crates and pillars cut short; hedges hide you, dark rugs slow their eyes, sneaking is silent, and walking too close draws them to the sound. A detection meter fills when you are seen — curious wardens come to look, a full meter trips the alarm and they chase. Clear a floor without ever tripping the alarm for a ghost bonus. Keyboard (WASD/arrows, Shift to sneak) and mouse (click the floor to walk there), pause, restart, synthesized Web Audio sounds, fully offline — every picture is drawn procedurally on canvas at run time, no image files, no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. `?shot=start&seed=1`, `?shot=play&seed=1` and `?shot=end&seed=1` freeze the game in its title, mid-heist and floor-clear states for screenshots.
